# MTV Россия — сайт-концепт

В репозитории находится адаптивная главная страница MTV Россия (`index.html`) с демонстрационной панелью управления.

## Быстрый просмотр на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Дождитесь публикации и откройте адрес, который GitHub покажет в этом разделе.

## Демо-панель

Кнопка **«Админ-панель»** расположена внизу справа.

- Демо-вход: `MTVA` / `MTVA`.
- Роли для демонстрации: **Создатель**, **Админ**, **Модератор**.
- Можно редактировать тексты сайта, новости, проекты и контактный email.
- Данные сохраняются в localStorage только текущего браузера; доступно скачивание JSON.

## Важно: демо, не production-CMS

Демо-вход и роли реализованы в браузере и не являются защищённой авторизацией. Не используйте этот вход для реального администрирования и не храните секреты в HTML/JavaScript.

Автоматическая синхронизация каналов `t.me/nextv_itv` и `t.me/mtv_1russia` пока не подключена. Для неё нужен серверный обработчик Telegram Bot API, база данных и переменные окружения на сервере. GitHub Pages подходит для статической демоверсии, но не запускает серверные функции.

## Безопасность Telegram

Файл `.env.local` удалён из текущей версии репозитория, потому что он содержал локальные секреты. **Удаление файла не удаляет его из истории Git.** Если токен Telegram-бота когда-либо попадал в репозиторий или чат, отзовите его через BotFather и создайте новый. Новый токен храните только в секретах серверного хостинга; не добавляйте его в репозиторий.

## Следующий этап для полноценной CMS

Чтобы сделать многопользовательскую систему с защищёнными аккаунтами, ролями на сервере, общей базой, модерацией и автоматическим импортом Telegram, потребуется backend (например, Next.js API + PostgreSQL) и развёртывание на серверном хостинге вроде Vercel. GitHub остаётся местом хранения исходного кода.
